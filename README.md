# 🚀 spring-boot-practice

A hands-on learning project for mastering **Spring Boot** from the ground up — REST API, Spring Data JPA, and Spring Security with JWT.

---

## 📚 Lessons

### Phase 1 — Spring Boot Fundamentals

### ✅ Lesson 01 — Project Structure & Auto-configuration
> `@SpringBootApplication` · `Auto-configuration` · `Classpath scanning`

- Explored project structure generated by Spring Initializr
- Understood how Spring Boot auto-configures beans based on classpath
- `@SpringBootApplication` = `@Configuration` + `@ComponentScan` + `@EnableAutoConfiguration`

---

### ✅ Lesson 02 — First Controller & Return JSON
> `@RestController` · `@GetMapping` · Jackson

- Created `HomeController` returning plain string response
- Created `StudentController` returning `List<Student>` as JSON
- Understood Jackson auto-converts Java objects to JSON

---

### ✅ Lesson 03 — application.properties
> `server.port` · `server.servlet.context-path` · `logging.level`

- Changed server port to `9090`
- Set context path to `/api`
- Configured logging level per package

---

### ✅ Lesson 04 — Spring Boot DevTools
> `spring-boot-devtools` · Hot reload

- Added DevTools dependency for automatic restart on file change
- Used `Ctrl+F9` to trigger rebuild and auto-restart

---

### Phase 2 — Spring Data JPA

### ✅ Lesson 05 — JPA Setup + H2
> `@Entity` · `@Id` · `@GeneratedValue` · H2 in-memory database

- Added `spring-boot-starter-data-jpa` and `h2` dependencies
- Annotated `Student` with `@Entity`, `@Id`, `@GeneratedValue`
- Verified Hibernate auto-creates table on startup via `spring.jpa.show-sql=true`

---

### ✅ Lesson 06 — JpaRepository & data.sql
> `JpaRepository` · `findAll()` · `data.sql`

- Created `StudentRepository` extending `JpaRepository<Student, Long>`
- Used `data.sql` to seed initial data into H2
- Called `findAll()` from controller — no SQL needed

---

### ✅ Lesson 07 — Service Layer & @Transactional
> `@Service` · `@Transactional` · Layered architecture

- Extracted business logic from controller into `StudentService`
- Applied `@Transactional` on service methods
- Controller only delegates to service — Single Responsibility

---

### ✅ Lesson 08 — Custom Query
> `Derived method names` · `@Query` · `@Param` · `Optional<T>`

- Added `findByName(String name)` using derived method naming
- Added `findByEmail(String email)` using `@Query` with JPQL
- Returned `Optional<Student>` to handle missing results safely

---

### Phase 3 — REST API

### ✅ Lesson 09 — ResponseEntity & Optional
> `ResponseEntity` · `Optional` · HTTP status codes

- Wrapped responses with `ResponseEntity` for status code control
- Used `Optional.map()` and `orElse()` to return `200` or `404`

---

### ✅ Lesson 10 — Request Body & Validation
> `@RequestBody` · `@Valid` · `@NotBlank` · `@Email`

- Added `POST /student` endpoint accepting JSON body
- Applied `@NotBlank` and `@Email` on `Student` fields
- Used `@Valid` to trigger validation on incoming request

---

### ✅ Lesson 11 — Global Exception Handling
> `@RestControllerAdvice` · `MethodArgumentNotValidException` · `ErrorResponse`

- Created `ErrorResponse` DTO with `status` and `message`
- Created `GlobalExceptionHandler` with `@RestControllerAdvice`
- Returned structured JSON error response on validation failure

---

### ✅ Lesson 12 — Pagination & Sorting
> `Pageable` · `PageRequest` · `Page<T>` · `Sort`

- Added `page`, `size`, `sortBy` as `@RequestParam` in controller
- Used `PageRequest.of(page, size, Sort.by(sortBy))` in service
- `findAll(pageable)` returns `Page<Student>` with metadata

---

### Phase 4 — Spring Security

### ✅ Lesson 13 — Security Setup
> `spring-boot-starter-security` · Default behavior

- Added Spring Security dependency
- Observed auto-protection of all endpoints with default login page

---

### ✅ Lesson 14 — In-memory Auth & SecurityFilterChain
> `SecurityFilterChain` · `InMemoryUserDetailsManager` · `HttpBasic`

- Configured `SecurityFilterChain` to permit `GET /students` and protect others
- Created in-memory user `admin/1234` with role `ADMIN`
- Tested with Basic Auth credentials via PowerShell

---

### ✅ Lesson 15 — JWT Authentication
> `JwtService` · `JwtFilter` · `AuthController` · `Bearer token`

- Created `JwtService` to generate and validate JWT tokens
- Created `JwtFilter` extending `OncePerRequestFilter` to intercept requests
- Created `POST /auth/login` endpoint returning signed JWT
- Registered `JwtFilter` in `SecurityFilterChain` before `UsernamePasswordAuthenticationFilter`

## 📌 Conventions Applied

- Javadoc on all public classes and methods (`@param`, `@return`, `@throws`)
- Single Responsibility Principle per class
- Constructor injection for all dependencies
- `final` fields that do not change after constructor
- `camelCase` / `PascalCase` / `UPPER_SNAKE_CASE` used correctly
- Sensitive config files excluded from version control
